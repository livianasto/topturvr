# Painel e KPIs

## Objetivo

Dar visão executiva do negócio sem criar uma segunda fonte de verdade.

## KPIs iniciais

| ID | Indicador | Frequência | Meta inicial |
| --- | --- | --- | --- |
| K01 | Tempo de primeira resposta | Semanal | ≤ 10 min |
| K02 | Conversão lead → venda | Semanal | Após 30 dias |
| K03 | Follow-ups no prazo | Semanal | ≥ 90% |
| K04 | Margem de contribuição por viagem | Por viagem | Por categoria |
| K05 | Variação custo previsto × realizado | Por viagem | ≤ 5% |
| K06 | Ocupação da saída | Semanal | Por produto |
| K07 | Distância do break-even | Semanal | ≥ 0 antes do gate |
| K08 | Viagens prontas em D-2 | Semanal | ≥ 95% |
| K09 | Conflitos de alocação | Semanal | 0 |
| K10 | NPS pós-viagem | Mensal | Após linha de base |
| K11 | Taxa de recompra | Mensal | Por segmento |
| K12 | Ações concluídas no prazo | Quinzenal | ≥ 80% |

## Critérios de aceite do MVP

- Cada cartão mostra definição, período, fonte e última atualização.
- Indicador sem dados aparece como “linha de base pendente”, nunca como zero.
- Alertas permitem navegar até o registro de origem.
- Filtros de período e produto são consistentes entre os cartões.
